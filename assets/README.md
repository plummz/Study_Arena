# Study Arena design assets

Prepared 2026-09-28 for the existing Study Arena Figma file. This is a project-specific working folder, not a redistributable illustration pack.

- `icons/`: 20 original Phosphor regular SVG icons. Sources was empty when inspected, so Phosphor was selected using the user's default.
- `illustrations/`: original unDraw Studying (onboarding), Empty (no sessions), and Winners (achievement) SVGs.
- `manifest.json`: per-file source URLs, license links, SHA-256 hashes, and Figma import status.
- `licenses/`: downloaded license evidence. Keep `phosphor-MIT.txt` with distributed copies.

Licensing: Phosphor is MIT, requiring retention of its copyright and permission notice. unDraw permits free personal/commercial project use without attribution, but prohibits redistribution as asset packs, competing services, and AI/ML model development. Do not publish this folder as a reusable illustration library. No paid or unclear-license assets were selected. Storyset assets were not used.

Figma assets: [External Assets — Study Arena](https://www.figma.com/design/9bmV20pkokhObHQufee8Vt/Study-Arena?node-id=17-2). All 23 SVGs were imported as editable vectors and visually checked. Per-asset node IDs are in the manifest and `figma-import.json`.

Wireframes and Prototype were not edited by Codex. Following the user's expanded request, Codex also created separate desktop and mobile high-fidelity concept pages; see `DESIGN_HANDOFF.md`. These concepts do not establish that app features are implemented.
